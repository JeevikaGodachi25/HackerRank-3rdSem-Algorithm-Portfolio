## 1. Mini-Max Sum

Find the minimum and maximum sums by excluding one value from the total sum.

**Time:** O(N)
**Space:** O(N)

## 2. Birthday Cake Candles

Find the tallest candle and count how many candles have that maximum height.

**Time:** O(N)
**Space:** O(1)

## 3. Insertion Sort – Part 1

Shift larger elements to the right and insert the required value into its correct position.

**Time:** O(N)
**Space:** O(1)

## 4. Binary Search

Search for an element in a sorted array by repeatedly dividing the search range into two halves.

**Time:** O(log N)
**Space:** O(1)

## 5. Mark and Toys

Sort toy prices and purchase the maximum number of toys possible within the available budget.

**Time:** O(N log N)
**Space:** O(N)
